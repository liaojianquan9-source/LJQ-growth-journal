# 年度总结 / 年度回顾

触发：用户说「写年度总结」「年度回顾」「总结今年」等。

## 素材收集

- 路径 A：**先读 `index.md` 目录**掌握全年概貌（标签频次、决策清单、记录节奏），再读 `weekly/` 全部周报（已是压缩后的信息），日记按需抽查全文。
- 路径 B：请用户粘贴周报/日记，或直接按下方 7 问引导对话。

## 起草框架（Sahil Bloom 个人年度回顾 7 问）

按 `assets/templates/annual.md` 起草，逐一回答：

1. 今年我改变了哪些想法？（2-3 个关键认知更新）
2. 什么给我创造了能量？（人/事/项目）
3. 什么消耗了我的能量？
4. 我的「船锚」是什么？（拖住我的人、心态、习惯——从「反复出现的问题」中识别，这是 AI 读全年记录最擅长替人做的事）
5. 我因为恐惧而没做什么？（拆解：做了的最坏结果 vs 最好结果）
6. 今年最大的成就与最大的失误？（客观各列，分析为什么成、为什么败）
7. 今年我学到了什么？（5-10 条变革性认知）

## 三条输出规则（来自年度回顾系统实践）

1. **正向结果 → 转成明年的具体安排**（写进日历/计划，不停留在「继续保持」）。
2. **负向结果 → 转成「如果 X，就 Y」触发式规则**。不写「我要改掉拖延」，写「如果到了 23 点还在刷手机，就把手机放到客厅」。
3. **最终输出克制**：结尾只留「明年要增加的 3 件事 + 明年要停止的 3 件事」。

## 章节结构（可选，用户需要完整版时）

工作 / 学习成长 / 生活体验 / 反思感悟 四板块分类，每板块用数据和具体事例支撑。

## 确认与落盘

陈列 → 用户修订（年度总结值得多改几轮）→ 路径 A 写入 `yearly/年度总结-YYYY.md`，路径 B 输出纯净 Markdown（一行文件名 + 一个代码块，零赘述）。
